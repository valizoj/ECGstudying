# 心電図ドリル

心電図検定の自習用HTMLアプリです。分野と出題範囲を選び、答えを思い出してから自己採点します。現在のカードは、フラッシュカード用に保存されていたPNG 52枚（001〜053、045欠番）を確認して作った49枚です。カードに対応する画像番号を表示します。

- 「復習＋未学習」は直近で覚えきれなかったカード、期限に達したカード、未学習カードの順で出題します。同じ優先度の中ではシャッフルします。
- 「もう一度」は同じ回の末尾に1回追加します。「覚えた」で次の復習まで1・3・7・14・30日と間隔が延びます。
- カード一覧は誘導名、病名、画像番号などで絞り込めます。学習記録は同じブラウザに保存されます。
- 元画像を見たい場合は「元画像・使い方」から番号付きPNGを選びます。ファイルはこの端末のブラウザ内だけに保存されます。
- iPhoneのSafariでは共有メニューの「ホーム画面に追加」が使えます。オンラインで初回の読み込みが完了すると、オフラインでも出題と記録が使えます。ブラウザのデータを消すと記録と読み込んだ画像も消えます。

## 更新方法

`cards.js` の配列に、固有の `id`、画像番号の配列 `sources`（拡張子なし）、`category`、`title`、`question`、`answer`、`point` を追記します。既存カードのIDを維持すると学習記録が引き継がれます。アプリやカードを更新して公開するときは `sw.js` の `cacheName` のバージョンを上げます。開いている旧版のタブを閉じて開き直すと新版に切り替わります。

GitHub Pagesでは `main` のルートをソースに設定します。開発時は `index.html` を直接開くか、`python -m http.server 8765` でローカル配信します。オフライン動作の確認にはlocalhostまたはHTTPSを使います。

カードの波形所見や数値は試験学習のための目安です。画像の限定的な記述は必要に応じて補いました。心筋虚血のST所見は [心筋梗塞の国際統一定義](https://doi.org/10.1161/CIR.0000000000000617)、QTの解釈は [ESC心室性不整脈ガイドライン](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/ventricular-arrhythmias-and-the-prevention-of-sudden-cardiac-death/) を参照してください。
