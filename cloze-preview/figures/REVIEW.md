# 追加模式図の選定

手元の52教材（045は欠番）を対象に、文章型で波形の形、測定点、測定区間を図にする利点を評価した。生成候補は、基線と注釈の対応、形の違い、文字の読みやすさ、穴の答えが図中に出ていないかを確認して選んだ。すべて学習用の模式図。

| 教材 | 判断 |
| --- | --- |
| 001 | 追加。P波の高さ、全幅、終末陰性成分の測る位置を比較。 |
| 002 | 鑑別リストを優先。異なる原因を単一のT波で代表させない。 |
| 003 | 既存の冠血管・誘導図と比較表を使用。 |
| 004 | 既存図の右室領域とV4Rの対応を使用。 |
| 005 | 追加。V3とⅢの測定点、同じ縮尺の3計算例。 |
| 006 | 007・051と比較できるため、文章の手がかりを維持。 |
| 007 | 既存の前壁誘導と冠血管の位置関係を使用。 |
| 008 | 既存の枝分かれと閉塞部位の図を使用。 |
| 009 | 原図に比較できる実例の形があり、追加図は重複。 |
| 010 | 原図で肥大部位と形を比較できる。 |
| 011 | 共通所見と型の比較を優先。 |
| 012 | 疾患と伝導時間の対応を表で確認。 |
| 013 | 病期による変化を短い箇条書きで確認。 |
| 014 | 原図に4種類のP′波が並ぶため、その比較を使用。 |
| 015 | 誘導の移行帯と起源の対応を原図で確認。 |
| 016 | 追加。MDIの2区間で開始点が共通であることを示す。 |
| 017 | 3誘導に分けた表で確認。 |
| 018 | 既存図の判読順と起源の図を使用。 |
| 019 | 既存の興奮方向と誘導極性を使用。 |
| 020 | 下の024にRP′の図をまとめ、教材を比較可能にした。 |
| 021 | 比較の軸は観察頻度と不整脈の対照表。 |
| 022 | 既存のリエントリーと起源の図を使用。 |
| 023 | 教材の開始時・停止時波形を使用。 |
| 024 | 追加。RR内で逆行性P′が現れる相対位置を比較。 |
| 025 | 期間の区分なので表で足りる。 |
| 026 | 心房粗動波の極性は既存の波形と表で確認。 |
| 027 | 追加。R開始とS最深部の2点を強調。数値閾値は伏せる。 |
| 028 | 原図でV1・V6の波形を比較。 |
| 029 | aVRの複数段階は原図と選択表で確認。 |
| 030 | 追加。幅・ノッチ・遅いT波を一列で比較。病型名は伏せる。 |
| 031 | QTcと臨床背景の関係。新しい数値入り波形は不要。 |
| 032 | 追加。QRS直後の低い振れがQRS本体やT波から区別できるように2度描き直した。 |
| 033 | 元教材に誘導別のペーシング波形があるためそれを使用。 |
| 034 | 元の刺激位置と伝導模式図を使用。 |
| 035 | 年齢ごとの範囲は表が適する。 |
| 036 | 孔の位置や誘導を元教材の解剖図で確認。 |
| 037 | 心室と血管の接続を元教材の解剖図で確認。 |
| 038 | 弁の偏位を元教材の解剖図で確認。 |
| 039 | 構造異常と誘導所見の対応表を使用。 |
| 040 | 左右の誘導変化を表で比較。 |
| 041 | 1図にまとめると病歴と所見の取り違えが起こりうる。対照表を使用。 |
| 042 | 3つの病歴を比較する表を使用。 |
| 043 | 病歴と時相を表で手早く比較。 |
| 044 | CPVTの波形例と術後粗動の元図を参照。 |
| 046 | 追加。P波の二峰性と二相性を別々に見比べる。 |
| 047 | 電極の位置は既存の装着図で確認。 |
| 048 | 左右負荷と疾患の対応。新規解剖図は不要。 |
| 049 | 年齢・性別・誘導による閾値の表を使用。 |
| 050 | 2つの場面に分ける表を使用。 |
| 051 | 既存の分岐図と誘導対応表を使用。 |
| 052 | 追加。Tの後の小さなUを、陽性・陰性で比較。 |
| 053 | 追加。初稿の下降型が盆状に見えたため、J点から下降するST部分を描き直した。 |

005は、測定位置を示す生成図に、同一縮尺と同一の基線を使う別の計算例を組み合わせた。0.25、約0.83、2.00の表示は、図の偏位量から計算した値。責任血管の候補は穴だけに表示される。[V3／Ⅲ比の原著](https://pubmed.ncbi.nlm.nih.gov/9856912/)・[MDIの原著](https://pubmed.ncbi.nlm.nih.gov/16567566/)・[ARVCの心電図所見を扱う原著](https://academic.oup.com/europace/article/25/3/1025/6986483)
